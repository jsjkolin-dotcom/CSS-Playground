CSS 没有"全部代码"，以下是全部核心知识点：选择器、属性、单位、布局、动画、新特性，共 16 个模块。点击顶部导航可快速跳转；点击右上角 ✕ 或按 Esc 关闭。


    

      
1
CSS 引入方式

      
    
        
  • 内联样式：style="属性:值;"
    • 
        
  • 内部样式表：<style> 标签写在 <head>
    • 
        
  • 外部样式表：<link rel="stylesheet" href="style.css">
    • 
        
  • @import 导入（不推荐，加载慢）
    • 
      

      
<div style="color:red"></div>

      
@import url("style.css");

      
优先级：!important > 内联 > ID选择器 > 类/属性/伪类 > 标签/伪元素 > 通配符 > 继承

    


    

      
2
选择器

      
基础选择器

      
* { } /* 通配符 */
div { } /* 元素/标签 */
.box { } /* class */
#id { } /* id */

      
组合选择器

      
div p {}        /* 后代 */
div > p {}      /* 子代 */
div + p {}      /* 相邻兄弟（下一个） */
div ~ p {}      /* 通用兄弟（后面所有） */

      
属性选择器

      
[attr] {}           /* 存在attr属性 */
[attr="val"] {}     /* 完全等于 */
[attr^="val"] {}    /* 开头 */
[attr$="val"] {}    /* 结尾 */
[attr*="val"] {}    /* 包含 */

      
伪类选择器（:）

      
:hover          /* 悬浮 */
:active         /* 点击激活 */
:focus          /* 获取焦点 */
:visited        /* 链接已访问 */
:link           /* 未访问链接 */
:first-child    /* 第一个子元素 */
:last-child
:nth-child(n)
:nth-last-child(n)
:first-of-type
:last-of-type
:nth-of-type(n)
:not(selector)  /* 排除 */
:checked        /* 单选复选框选中 */
:disabled
:empty          /* 空标签 */
:root           /* html根元素 */

      
伪元素（::，创建虚拟元素）

      
::before    /* 元素前面，必须content */
::after     /* 元素后面，必须content */
::first-line
::first-letter
::selection /* 选中文字样式 */

    


    

      
3
单位

      
绝对单位

      
px 像素，cm mm in pt pc（打印用，网页基本不用）

      
相对单位

      
    
        
  • em：相对于父元素字体大小
    • 
        
  • rem：相对于根元素 html 字体大小
    • 
        
  • vw：视口宽度 1vw = 视口 1% 宽
    • 
        
  • vh：视口高度
    • 
        
  • vmin：vw/vh 较小者
    • 
        
  • vmax：vw/vh 较大者
    • 
        
  • %：百分比，参照父元素对应属性
    • 
      

      
颜色单位

      
red;
#ff0000;
rgb(255,0,0);
rgba(255,0,0,0.5); /* a透明度0~1 */
hsl(0,100%,50%);
hsla(0,100%,50%,0.5);

    


    

      
4
文本与字体属性

      
color: #000;                 /* 文字颜色 */
font-size: 16px;             /* 字号 */
font-weight: bold;           /* 字重 normal/bold/100~900 */
font-family: "微软雅黑",sans-serif; /* 字体 */
font-style: italic;          /* 斜体 */
line-height: 1.5;            /* 行高 */
text-align: center;          /* 水平对齐 left/center/right/justify */
text-decoration: none;       /* 下划线 none/underline/overline/line-through */
text-indent: 2em;            /* 首行缩进 */
text-shadow: 2px 2px 3px #000;/* 文字阴影 x y 模糊 颜色 */
letter-spacing: 2px;         /* 字间距 */
word-spacing: 4px;           /* 单词间距 */
text-transform: uppercase;   /* 大小写 uppercase/lowercase/capitalize */
white-space: nowrap;         /* 换行 normal/nowrap/pre */
overflow-wrap: break-word;   /* 长单词换行 */

      
简写

      
font: italic bold 16px/1.5 "Microsoft Yahei";

    


    

      
5
盒子模型（Box Model）

      
标准盒模型：width/height = content宽度
IE 怪异盒模型：width = content+padding+border

      
box-sizing: content-box; /* 默认标准盒 */
box-sizing: border-box;  /* 怪异盒，开发最常用 */

width: 200px;
height:200px;
padding: 10px;           /* 内边距 上右下左 */
border: 1px solid #ccc;  /* 边框 宽度 样式 颜色 */
margin: 20px;            /* 外边距，会margin塌陷 */

      
border 细分

      
border-width:1px;
border-style: solid/dashed/dotted/none;
border-color:#333;
border-radius: 8px;      /* 圆角 */

      
背景属性

      
background-color:#fff;
background-image:url("bg.jpg");
background-repeat: no-repeat; /* repeat/no-repeat/repeat-x/y */
background-position: center;  /* x y */
background-size: cover;       /* cover/contain/px/% */
background-attachment: fixed; /* 背景滚动 fixed/scroll */
background-origin: padding-box;
background-clip: border-box;

      
简写

      
background: #fff url(bg.jpg) no-repeat center / cover;

    


    

      
6
浮动 float（旧布局）

      
float: left / right / none;
clear: left / right / both; /* 清除浮动 */

      
浮动副作用：父元素高度塌陷。清除浮动方案：overflow:hidden；伪元素 after；clear:both

    


    

      
7
定位 position

      
position: static;    /* 默认，无定位 */
position: relative;  /* 相对自身原位置，不脱离文档流 */
position: absolute;  /* 绝对定位，脱离文档流，参照最近非static父 */
position: fixed;     /* 固定定位，参照视口 */
position: sticky;    /* 粘性定位，relative+fixed结合 */
top/right/bottom/left;
z-index: 99;         /* 堆叠层级，仅定位元素生效 */

    


    

      
8
Flex 弹性布局（现代布局）

      
父容器（display:flex）

      
display: flex;
flex-direction: row; /* row/column/row-reverse/column-reverse */
flex-wrap: wrap;     /* nowrap/wrap/wrap-reverse */
justify-content: center; /* 主轴对齐 flex-start/center/flex-end/space-between/space-around */
align-items: center;     /* 交叉轴单行对齐 */
align-content: center;   /* 多行交叉轴对齐 */
gap: 10px; /* 间距 */

      
子项

      
flex-grow: 1;    /* 放大比例 */
flex-shrink: 1;  /* 缩小比例 */
flex-basis: 100px;/* 基础尺寸 */
flex:1; /* 简写 flex: grow shrink basis */
align-self: center; /* 单独子项交叉轴对齐 */
order: 2; /* 排序，数字越小越靠前 */

    


    

      
9

父容器

      
display: grid;
grid-template-columns: 1fr 1fr 1fr;
grid-template-rows: 100px 200px;
gap: 10px;
justify-items: center;
align-items: center;
justify-content: center;
align-content: center;

      
子项

      
grid-column: 1 / 3;
grid-row: 1 / 2;
grid-area: name;

    


    

      
10
变换、过渡、动画

      
transform 变换

      
transform: translate(10px,20px); /* 位移 */
transform: rotate(45deg);        /* 旋转 */
transform: scale(1.2);           /* 缩放 */
transform: skew(10deg);          /* 倾斜 */
transform-origin: center;        /* 变换原点 */

      
transition 过渡

      
transition: all 0.3s ease;
/* 属性 时长 缓动函数 延迟 */
transition: width 0.3s linear 0s;

      
animation 动画

      
/* 定义动画 */
@keyframes move {
  0% {transform: translateX(0);}
  100% {transform: translateX(100px);}
}
/* 使用 */
animation: move 2s infinite alternate;
/* 名称 时长 缓动 延迟 次数 是否反向 */

      
缓动函数：ease / linear / ease-in / ease-out / ease-in-out / cubic-bezier()
