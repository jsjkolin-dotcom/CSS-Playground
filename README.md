# CSS Playground — 前端实时演示工作台

一个**纯单文件**的前端教学/演示工作台：HTML 里内置全部 CSS 与 JavaScript，双击即可在浏览器打开，无需安装、无需构建、离线可用（图表库除外，走 CDN）。

左边写代码、右边立刻看效果、右侧面板拖滑条同步改样式，三向实时联动，既是学习 CSS 的活教材，也是讲课时现场演示的利器。

## 六大演示模块

顶部下拉切换六大模块，每个模块独立记忆状态，切换零残留。

### ① CSS 基础盒子

- 盒子数量 1–10 可调，`nth-child` 单选定位任一盒子单独调样式
- 属性面板覆盖：宽高、内边距、外边距、边框（宽度/样式/颜色）、圆角、背景色、文字（字号/颜色/对齐）
- 实时展示标准盒模型

### ② CSS 特效（变换/阴影/渐变）

- **变换 Transform**：旋转、缩放、平移 X/Y、倾斜
- **阴影**：box-shadow（X/Y 偏移、模糊、扩散、颜色）、text-shadow
- **渐变**：线性渐变角度 + 双色渐变
- **文字**：字重、字间距、行高
- **过渡 Transition**：时长 + 缓动函数选择
- **Hover**：鼠标悬浮态独立配置（悬浮色/缩放/阴影），实时所见即所得

### ③ CSS 动画（@keyframes）

内置 **11 种** 常用 @keyframes 动画，点击即播放、即生成代码：

| 动画       | 效果   |
| -------- | ---- |
| fade     | 淡入淡出 |
| fadeInUp | 上移淡入 |
| pulse    | 心跳脉冲 |
| bounce   | 弹跳   |
| shake    | 抖动   |
| swing    | 摆动   |
| rotate   | 旋转   |
| zoom     | 缩放呼吸 |
| flip     | 翻转   |
| slide    | 滑入滑出 |
| jelly    | 果冻晃动 |

可调：动画时长、延迟、次数（infinite）、方向、缓动函数。

### ④ ECharts 图表

- 内置 **6 种** 图表：柱状图、折线图、饼图、散点图、雷达图、仪表盘
- 属性面板动态生成：每种图表展示它专属的可调属性与数据
- 数据可直接在面板里改，代码区同步生成完整 `option`
- 支持手改代码，反向解析回面板

### ⑤ VChart 图表

对标 [visactor.com/vchart/example](https://visactor.com/vchart/example)，内置 **21 种** 图表，每个图表的属性面板按官方配置项组织为 **12 个折叠分组、20–46 个控件**：

> bar（柱状）· line（折线）· area（面积）· pie（饼图）· ring（环图）· rose（玫瑰）· scatter（散点）· radar（雷达）· gauge（仪表）· funnel（漏斗）· waterfall（瀑布）· heatmap（热力）· boxplot（箱线）· sankey（桑基）· treemap（矩形树图）· sunburst（旭日）· circlepacking（圆填充）· wordcloud（词云）· liquid（水波）· progress（进度）· venn（韦恩）

面板分组（对齐官方 spec 文档）：

| 分组             | 内容                                                                   |
| -------------- | -------------------------------------------------------------------- |
| 数据 Data        | 类目/数值/系列数据编辑                                                         |
| 系列与样式 Series   | 各图表专属样式（如漏斗 `funnelAlign`、词云 `fontSizeRange`、进度图 `track`/`progress`） |
| 标签 Label       | visible / position / 字号 / 颜色                                         |
| 标题 Title       | 主标题 / 副标题 / 对齐                                                       |
| 图例 Legend      | 显隐 / 位置                                                              |
| 提示框 Tooltip    | 显隐 / 跟随模式                                                            |
| 交互状态 state     | 官方 hover / hover_reverse / selected 图元状态                             |
| 坐标轴 Axes       | 轴显隐 / 刻度 / 网格 / Y 轴 min-max（直角系 7 种图）                                |
| 十字准线 Crosshair | x/y 准线显隐                                                             |
| 缩略轴 DataZoom   | slider 型，start/end 比例                                                |
| 动画 Animation   | 入场动画开关 / 时长 / 缓动                                                     |
| 画布 Canvas      | 背景 / 内边距 / 色板颜色                                                      |

### ⑥ 组合 Box 模式

多盒子组合布局演示，面板改动通过增量补丁精确写回代码对应声明块，三区联动同基础模块。

## 使用方法

### 打开即用

```
双击 css-playground.html
```

推荐用 **Chrome / Edge** 打开。文件不到 250KB，一个文件就是整个工具。

### 典型工作流

1. 顶部下拉选择演示模块（CSS 基础 / 特效 / 动画 / ECharts / VChart / 组合）
2. 图表模块下再选具体图表类型
3. 右侧属性面板拖滑条、选颜色、勾开关 —— 左侧代码同步更新并**滚动定位高亮**对应行
4. 也可以直接在代码区手写：自动语法高亮、上下文补全、回车自动缩进对齐
5. 满意后点「复制代码」带走

### 快捷键

| 按键              | 作用                |
| --------------- | ----------------- |
| `1`–`4`         | 切换布局（三栏/两栏/全屏预览…） |
| `Tab` / `Enter` | 采纳补全项             |
| `Esc`           | 关闭补全列表            |

## 代码编辑器特性

手写的编辑器（不依赖 CodeMirror/Monaco 等外部库）：

- **双层渲染**：透明 `textarea` 接收输入 + 底层 `<pre>` 渲染高亮层，字号行高严格对齐，肉眼无感切换
- **状态机高亮**：`highlightCSS` 逐字符扫描，正确处理 `@media` 参数段、颜色值、注释等状态
- **上下文补全**：`suggestContext` 根据光标前词元判断该补属性名还是颜色值，`#` 直接触发色板
- **回车智能缩进**：`smartEnter` 继承上一行缩进，遇 `}` 自动回退，不会多出两个空格
- **滚动同步**：用 `pre.scrollTop` 编程式滚动（而非 transform），彻底避免向上滚动时文字"跑出"裁剪区

## 技术架构

```
┌─────────────┬──────────────┬─────────────┐
│  代码区      │   效果区      │  属性面板    │
│  textarea   │  iframe /    │  滑条/颜色/  │
│  (透明文字)  │  canvas      │  勾选/下拉   │
│  + 高亮层   │              │             │
└──────┬──────┴──────┬───────┴──────┬──────┘
       │             │              │
       │  手改代码 → 300ms 防抖反向解析 parseCSS / ecParseOption / vcParseSpec
       │             │              │
       │  面板改动 → 增量补丁 patchDeclBlock / patchBoxCode / patchEChartsCode / patchVChartCode
       │             │              │
       ▼             ▼              ▼
              三向状态同步 (demoState)
```

关键实现：

- **增量补丁体系**：面板改动不重写整份代码，而是定位到目标声明块精确插入/替换，保持用户手写格式不丢
- **反向解析**：手改代码后 300ms 防抖解析回 `demoState`，面板闭包动态取当前 `spec` 引用，双向写不串台
- **VChart 尺寸重建策略**：VChart 1.13 的 `resize()` 存在 canvas 被清零的缺陷，改为"尺寸真实变化时 200ms 防抖整体重建"，并做容器归属校验防串渲染
- **liquid / venn 按需注册**：UMD 构建默认不含这两个系列，加载时显式 `registerLiquidChart()` / `registerVennChart()`

## 常见问题

**Q：图表区空白？**  
图表模块依赖 CDN，确认网络可用。脚本内置双 CDN 兜底，一般无需处理；公司内网屏蔽 jsdelivr 时可手动把 `<script src=...>` 换成可达镜像。

**Q：代码区打字看不见字？**  
编辑器用"透明文字 + 高亮层"双层实现，若被浏览器插件（如暗色模式强制器）改了 textarea 颜色可能异常，换无痕窗口验证。

**Q：分栏拖拽后图表消失？**  
已通过"尺寸变化防抖重建"修复；若仍有，刷新页面即可（状态在内存中，刷新重置）。
